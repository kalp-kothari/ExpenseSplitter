---
name: SETTLE Phase 1 scope
description: Scope guard for the SETTLE dashboard foundation and polish pass.
---

SETTLE Phase 1 work is limited to the UI foundation and visual polish. Do not add authentication, a backend, a database, or real group, expense, or settlement workflows unless the user explicitly starts or requests Phase 2.

**Why:** the user repeated the Phase 1-only scope in the project briefs.

**How to apply:** keep sample data local and unfinished actions clearly preview-only; limit changes to layout, theme, visual quality, responsiveness, and usability.
